# ConfoVHH product 0.9.0

Product 0.9.0 improves research usability, evidence integrity, and release traceability while preserving the digest-attested v0.5.0 scientific engine and every frozen validation artifact.

## Research workflow

- Replaces automated retain/deprioritize recommendations with neutral coordinate-geometry flags. These flags are not validated candidate-selection, ranking, or experimental-hit rules.
- Preserves legacy wording inside the canonical v0.5 engine record for reproducibility while mapping it to neutral language in the current product display and researcher handoff brief.
- Clears researcher-authored dispositions whenever a prediction run is recomputed and binds exported decisions to exact coordinate, audit-result, PAE, and topology evidence identifiers.
- Clarifies first-use navigation, qualified evidence labels, export names and contents, mobile limitations, and the experimental worked-example boundary.
- Verifies the exact byte count and SHA-256 of the remotely fetched worked example before parsing it.

## Integrity and accessibility

- Neutralizes CSV formulas even when trigger characters follow leading whitespace or Unicode format characters.
- Adds response-level content security, framing, referrer, MIME-sniffing, and permissions headers.
- Rejects non-read HTTP methods before framework routing and publishes a dated triage of installed dependency advisories without weakening the frozen engine attestation.
- Improves supporting-text size and contrast and adds a real Chromium/WCAG A/AA acceptance gate.
- Adds measured core coverage floors and CI on Node 22.18 and Node 24.

## Release traceability

- Adds full-SHA-pinned GitHub Actions, exact producer-output regression as a distinct check, and a CI-gated product-release workflow.
- Release assets include deterministic source and production archives, CycloneDX SBOM, provenance receipt, and `SHA256SUMS`.
- Documents that legacy attestation commits resolve as ancestors in the Sites source history but are absent from the current public GitHub repository, while their recorded digests remain verifiable and are bound to the reachable product tag.

No binding, affinity, specificity, functional-state, membrane-compatibility, candidate-selection, near-native-ranking, or hard-decoy holdout claim is added.
