This repository publishes the current application and its retained validation files as an administrative derivative dated 22 October 2026. The complete earlier repository history, branches and release assets remain preserved in private archives and verified backups.

One obsolete deployment URL was set to `null` in `publicProductPreservation.siteUrl` in the v2 census specification. No scientific measurements, thresholds, sequences, target membership, protocol text, historical dates or decision flags changed. The dependent checksum manifests and verification constants were updated for this public copy. These new checksums verify the derivative files; they must not be cited as the original historical attestations.

[PUBLIC_SNAPSHOT.json](provenance/PUBLIC_SNAPSHOT.json) identifies the source revision and lists every affected file with its original and public SHA-256. All other pre-existing files except the README notice are byte-for-byte unchanged from that source revision. Original private archives were not modified.

Historical commit links, historical release links and targets in `provenance/REVISION_MAP.json` are archival references and may not resolve for anonymous readers. Branch-only research and original release downloads are preserved privately; their preservation does not imply public availability.
