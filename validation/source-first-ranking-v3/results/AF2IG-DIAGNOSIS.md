# AF2IG no-contact diagnosis

The released AF2IG structures contain separated, low-confidence joint predictions. There is no evidence that ConfoVHH parsing introduced a translation, nor evidence supporting a simple coordinate export repair. The exact author-modified producer and exact reordered input files are absent, so a producer-side implementation problem cannot be categorically excluded.

Independent checks used all 200 original PDBs and 200 original PAE arrays. Every coordinate/PAE hash matches the extraction inventory; every coordinate also matches the frozen score manifest. Every PAE interaction mean matches its archived producer score within score-file rounding. No per-pose ranking or reference-quality files, or native coordinates, were read for this diagnosis. Published aggregate findings and prior development exposure exist; this is not a blinded holdout study.

Receptor Cα conformations remain stable across seeds (all pairwise-to-seed01 RMSDs <=0.49 Å). Nanobody placement varies substantially after fitting the receptor; the receptor-aligned VHH Cα RMSD reaches 92 Å. Nanobody internal confidence also varies, so these are not simply one rigid binder shifted by a common constant. The original files list binder chain A first and receptor B second, with unique global residue numbers across the chains. Chain continuity diagnostics are saved; jumps in engineered receptor constructs are not silently repaired. A preliminary summary compared chain-qualified identity strings; the final report normalizes residue numbers before checking cross-chain overlap, and both versions are retained for transparency.

The archived job invokes `predict_mod.py`, seeds 1–50, model_2_ptm, and full PAE export. The [published methods](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0355549) describe reordering the input with binder first and modifying the wrapper for seed and PAE output. The archived code does not include that modified producer or its version pin. The recovered official public [predict.py](https://github.com/nrbennet/dl_binder_design/blob/main/af2_initial_guess/predict.py) and [af2_util.py](https://github.com/nrbennet/dl_binder_design/blob/main/af2_initial_guess/af2_util.py) generate one joint final_atom_positions array, write that predicted protein, and then insert chain endings via PyRosetta. Their output path contains no explicit independent per-chain centering or docking step. This is a code-path inspection, not execution of the missing author version, and does not prove absence of an upstream bug.

A further read-only check of current official [Rosetta Pose.cc](https://github.com/RosettaCommons/rosetta/blob/main/source/src/core/pose/Pose.cc) and [Conformation.cc](https://github.com/RosettaCommons/rosetta/blob/main/source/src/core/conformation/Conformation.cc) shows append_pose_by_jump delegating to insert_conformation_by_jump, which clones the source residues, updates numbering and rebuilds the atom tree. No coordinate translation is inserted in that path. Saved function excerpts support the interpretation that chain-ending insertion is not an intentional chain separation operation; this still does not validate the absent author-specific binary/version.

Actionable generation work is an instrumented, explicitly new reconstruction, not relabeling these 200 outputs as repaired. Before any rerun: pin the original producer/weights or state the substitute version; recover and hash the exact reordered initial-guess input and complete construct sequences; verify binder-first order, global indices, chain breaks and target/template masks; save the joint AF2 coordinates and PAE before PyRosetta, the final saved PDB, and an invariant check that export preserves all interchain distances within rounding. Use a smoke case to validate this boundary before scheduling seeds. Keep all attempted seeds and original failures. Do not force contact by translating chains or independently aligning monomers.

A scientific rerun is honest only with its input regime declared. Reconstructing exact published initial guesses requires the missing preprocessing artifact or a documented reconstruction. Substituting a predicted-monomer initial guess is a different regime. Using an experimental dimer as the joint initial guess exposes the native relative pose and cannot become an independent validation result. The evidence currently supports diagnosing a generation/pose-availability failure, not claiming that ranking can recover absent interfaces. No GPU or new prediction was run for this diagnosis.
