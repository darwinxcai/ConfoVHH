# Submission kit

[Submission readiness](../SUBMISSION_READINESS.md) states the five gates in
prose. This directory holds the forms that close them and the command that
reports which are still open:

```bash
node scripts/paper/submission-status.mjs
```

It prints one line per gate, what is missing, and who has to supply it. It exits
non-zero until every gate is closed, so it cannot be mistaken for a green light.
It checks the repository only. It cannot judge whether the science is worth
publishing.

## What is here

| File | What it is | Who fills it |
|---|---|---|
| [`submission-record.json`](submission-record.json) | Authorship, affiliations, contributor roles, funding, competing interests, AI disclosure, data availability, and the reviewed release | The author |
| [`deposition-manifest.json`](deposition-manifest.json) | Every retained evidence file a public archive must carry, with byte counts and SHA-256 digests | Regenerated by script; the `deposit` block is the author's |
| [`independent-evaluations/`](independent-evaluations/RECORD_SCHEMA.md) | One record per outside researcher who completes the workflow task sheet | The participant, transcribed verbatim |
| [`REVIEWER_INVITE.md`](REVIEWER_INVITE.md) | A draft message the author can send to ask someone to do that | The author sends it |

## Three things only a person can do

**Ask one outside researcher to run the workflow task sheet.** Two gates depend
on this and nothing in the repository can substitute for it. The task is
[a short synthetic exercise](../WORKFLOW_EVALUATION.md) on two four-residue
fragments, roughly twenty minutes. It shows that someone else can operate and
reproduce the software. It does not show that the ranking picks better binders,
and the manuscript must not imply that it does. A draft invitation is in
[`REVIEWER_INVITE.md`](REVIEWER_INVITE.md); no message has been sent.

**Deposit the retained evidence somewhere durable and permitted.** The manifest
names the exact files. Two questions have to be answered before uploading: does
the source of each input permit redistribution, and under what licence is the
deposit released. The 85 preliminary cognate model coordinates and the full
per-model PAE matrices are missing and stay missing; the paper accounts for them
explicitly rather than dropping them from the denominator.

**Write down the submission facts.** Author list and order, affiliations,
contributor roles, funding, competing interests, and an AI-use disclosure
covering the whole project. These are statements about people and cannot be
inferred from the code.

## Regenerating the manifest

```bash
node scripts/paper/build-deposition-manifest.mjs          # rewrite it
node scripts/paper/build-deposition-manifest.mjs --check  # fail if it is stale
```

The generator lists tracked files only, refuses to describe an empty component,
and refuses outright to include anything under the independent hard-decoy
holdout. It preserves an existing `deposit` block across regeneration.

## What this kit does not claim

Closing every gate means the submission is administratively complete and its
software claims are reproducible. It says nothing about novelty, significance,
or acceptance. The central retrospective result remains negative: ConfoVHH
selected an acceptable model in 18 of 33 jobs against 19 of 33 for the maximum
exported predictor score, across only four jobs that contained both acceptable
and poor interfaces, all on one reference complex. The independent hard-decoy
protocol is a separate record and has not passed.
